E-Auto Verbrauch – PWA

Installation:
1. Den Inhalt dieses Ordners auf einen HTTPS-Webserver laden (z. B. GitHub Pages).
2. Die Seite auf dem Android-Gerät in Chrome öffnen.
3. Im Browser-Menü „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ wählen.

Funktionen:
- Ladevorgänge lokal speichern
- kWh/100 km berechnen
- Brutto-/Nettokosten mit MwSt.
- Kosten pro Monat als Balken
- Ladehistorie
- anpassbare Dashboard-Kachelfarben
- CSV-Export (Excel-kompatibel, Semikolon/Dezimalkomma)
- Offline-Grundfunktion über Service Worker

Hinweis:
Die Daten werden im Browser lokal gespeichert. Vor Browser-/App-Datenlöschung sollte ein CSV-Export als Sicherung erstellt werden.
